# 情境簡報：爭取資源 / Headcount · Budget · Air cover

> **標示：內容模板 (content template) — 不是預設美工排版**  
> Agent **只學**報告內容與決策風格：BLUF、stakes、options、REC、期限、章節意圖、故事線。  
> **不要**照抄 sample PPTX 的配色、字級、版心、座標或裝飾；真實交付用公司母片，只遷移本檔結構與話術。詳見 [presentations/README](README.md)「內容模板 ≠ 美工」。

**場合：** 年度/季度 HC 申請、臨時增援、預算、要求老闆公開站台  
**聽眾：** 直屬主管、資源委員會、偶有 HR  
**時長：** 20–30 min（預讀一頁更佳）  
**Skills：** (b) · (d) · (a) · capacity model  

---

## BLUF

> **Ask:** +[N] [role] (or \$Z) to deliver [outcome] by [date].  
> **If no:** [which commits slip] — explicit.  
> **Recommend:** Approve full / partial Option B.  
> **Decide by:** [date] (hiring lag 3–6 mo if HC).

---

## Slide outline

| # | 標題句 | 內容 |
|---|--------|------|
| 1 | **BLUF ask** | 角色/金額/期限 |
| 2 | **Linked outcomes** | Roadmap 哪幾條、公司 OKR |
| 3 | **Capacity math** | 用 [capacity model B](../shared/capacity-model.md)：需求 − 現有 + **20–30% unplanned** |
| 4 | **Role definition** | 填補的 **capability gap**（不是「很忙」） |
| 5 | **Options** | Full / partial / descope no-hire |
| 6 | **If declined** | 透明後果表 |
| 7 | **Alternatives tried** | 外包、重排、自動化 |
| 8 | **Timeline** | 開缺 → offer → productive |
| 9 | **Decision** | 簽核人 + 日期 |
| B | JD 草稿、市場薪資區間（若需要） | |

## 話術（中英）

- EN: “This is a trade-off decision, not a comfort request.”  
- ZH:「這是要您在『加人』與『砍範圍』之間做選擇，不是單位喊痛。」  

Air cover：

> “Need you to restate in steering that [initiative] outranks [X], so partner teams stop treating it optional.”
