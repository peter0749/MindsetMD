# 情境簡報：期末呈現 / QBR · 季末 · 年終 close

**場合：** Quarterly business review、半年檢、年終部門報告  
**聽眾：** 直屬主管、有時更上層或跨 BU  
**時長：** 30–45 min  
**Skills：** (e) · (a) · (d)  

---

## BLUF

> **Period status:** Green/Yellow/Red vs commits.  
> **Top outcomes:** 3 bullets with metrics.  
> **Top miss / risk carried:** 1 bullet + disposition.  
> **Next period focus + ask:** [endorse priorities / resource / none].

結構對齊常見 **Leadership QBR**：Exec summary → metrics → initiatives → risks → decisions（answer-first）。

---

## Slide outline

| # | 標題句 | 內容 |
|---|--------|------|
| 1 | **Executive summary（整季一句話）** | 狀態 + 3 wins + 1 challenge |
| 2 | **Scorecard vs commits** | 期初承諾表：Hit / Partial / Miss |
| 3 | **Outcome deep-dive（選 2）** | 每個：goal → result → why it mattered |
| 4 | **Metrics trend** | 3–6 KPI，12 週或季度趨勢 |
| 5 | **Initiatives progress** | 進行中項目 % 或 gate |
| 6 | **What slipped & why** | 假設哪個破了；**不是甩鍋秀** |
| 7 | **Org / capacity learnings** | 負荷、技能、流程一頁 |
| 8 | **Risks into next period** | 帶入下期的債與依賴 |
| 9 | **Proposed next priorities** | 連到 [08](08-period-start-planning.md) 草案 |
| 10 | **Asks / decisions** | 資源、範圍、決策期限 |
| B | 完整 KPI、人員、財務附表 | |

## 外商 QBR 口味

- 少活動、多 **implication**（“so what / now what”）  
- 同模板每季重複 → 可看趨勢  
- 6–10 頁主軸；附錄給愛問細節的人  

## 竹科 / 年底口味

- 對客戶 program / silicon 節點交代清楚  
- 風險「是否影響明年 design-win」用事業語言  
- 公開場合先肯定合作單位，細節爭議會前 pre-wire
